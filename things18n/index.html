things18n

A tiny library that makes a plain web page speak more than one language. One script tag. No build. No dependencies. No server. It works when you double-click the HTML file, and it's the thing translating this very page (and the whole indiethings notebook, and MeAsocie).

You write your page normally. Where text should change, you add a data-t attribute. You put the translations in a small JavaScript object. That's the whole idea.

things18n

Uma biblioteca minúscula que faz uma página web comum falar mais de um idioma. Uma tag de script. Sem build. Sem dependências. Sem servidor. Funciona dando dois cliques no arquivo HTML, e é ela que traduz esta página mesma (e o caderno indiethings inteiro, e o MeAsocie).

Você escreve a página normalmente. Onde o texto precisa mudar, coloca um atributo data-t. As traduções ficam num objeto JavaScript pequeno. É essa a ideia toda.

quickstart

Nothing to install, nothing to build, and no Node. It's one plain JavaScript file that you load straight from here (or copy next to your page: see where to get it).

1. Load it in the <head>, synchronously (no defer, no async). There is nothing to configure: the language your HTML is written in is whatever <html lang> says, and the other languages are the ones you add.

começando

Nada para instalar, nada para compilar, e sem Node. É um arquivo JavaScript comum que você carrega direto daqui (ou copia para perto da sua página: veja onde pegar).

1. Carregue no <head>, de forma síncrona (sem defer, sem async). Não tem nada para configurar: o idioma em que o seu HTML está escrito é o que o <html lang> diz, e os outros idiomas são os que você adicionar.

<html lang="en">
<head>
  <script src="https://meoriente.com.br/indiethings/things18n/things18n.js" data-switcher></script>
  <script>
    things18n.add('pt-BR', {
      'Hello, world': 'Olá, mundo',
      'Save changes': 'Salvar alterações'
    });
  </script>
</head>

2. Mark the text that should change. The text itself is the key, so you don't invent names and you never have to write the default language twice:

2. Marque o texto que deve mudar. O próprio texto é a chave, então você não inventa nomes e nunca precisa escrever o idioma padrão duas vezes:

<body>
  <h1 data-t>Hello, world</h1>
  <button data-t>Save changes</button>
  <input placeholder="Search" data-t-attr="placeholder">
</body>

3. There is no step 3. data-switcher added a small language switcher to the corner of the page. Visitors get their browser's language the first time, and their choice is remembered after that.

Check what's still untranslated by adding ?i18n=debug to the page's address: no tools, just the browser (see finding what's missing).

3. Não tem passo 3. O data-switcher colocou um seletor de idioma no canto da página. O visitante recebe o idioma do navegador na primeira vez, e a escolha dele fica lembrada depois.

Veja o que ainda falta traduzir adicionando ?i18n=debug ao endereço da página: sem ferramentas, só o navegador (veja achando o que falta).

in your HTML

Two styles, and you can mix them on one page. Key-less (data-t) uses the text you wrote as the key: the quickest way to translate a page. Keyed (data-i18n) uses a name you pick: better for apps, for text that is edited often, and for the same words meaning different things.

no seu HTML

Dois estilos, e dá para misturar na mesma página. Sem chave (data-t) usa o texto que você escreveu como chave: o jeito mais rápido de traduzir uma página. Com chave (data-i18n) usa um nome que você escolhe: melhor para apps, para texto que muda muito e para as mesmas palavras com sentidos diferentes.

data-t
Key-less. The element's own text is the key, matched ignoring extra spaces and line breaks. Put it on the innermost element: one that holds other elements is skipped (and you get a console warning). The text you wrote is also the fallback. Sem chave. O próprio texto do elemento é a chave, comparado sem ligar para espaços e quebras de linha extras. Coloque no elemento mais interno: um que contém outros elementos é ignorado (e aparece um aviso no console). O texto que você escreveu também é o fallback.
data-t-attr="placeholder aria-label"
Key-less for attributes: the attribute's value is the key. List as many attributes as you want, separated by spaces. Sem chave para atributos: o valor do atributo é a chave. Liste quantos atributos quiser, separados por espaço.
data-i18n="key"
Keyed. Replaces the element's text. Put it on the innermost element, since all children are replaced. Works on <title> too. Com chave. Troca o texto do elemento. Coloque no elemento mais interno, pois todos os filhos são substituídos. Funciona no <title> também.
data-i18n-html="key"
Same, but the translation may contain HTML (<b>, links…). Opt-in on purpose: only use it with strings you wrote, never with user input. Igual, mas a tradução pode ter HTML (<b>, links…). É opt-in de propósito: só use com textos que você escreveu, nunca com entrada de usuário.
data-i18n-attr="attr:key; attr2:key2"
Translates attributes: placeholder, aria-label, title, alt, content on a <meta>… Traduz atributos: placeholder, aria-label, title, alt, content de um <meta>…
data-i18n-params='{"name":"Ana"}'
Values for {name} placeholders in the message, in keyed and key-less mode. Must be valid JSON. Valores para os {name} da mensagem, nos modos com e sem chave. Precisa ser JSON válido. 
<h1 data-i18n="hello" data-i18n-params='{"name":"Ana"}'>Hello, Ana!</h1>
<input placeholder="Search" data-i18n-attr="placeholder:search; aria-label:search">
<title data-i18n="meta.title">My page</title>
<meta name="description" content="..." data-i18n-attr="content:meta.description">

If a key is missing in the current language, things18n falls back to the default language's dictionary, and then to whatever you wrote in the HTML. A half-translated page is never blank and never shows raw keys.

Se uma chave não existe no idioma atual, o things18n recorre ao dicionário do idioma padrão e, depois, ao que você escreveu no HTML. Uma página traduzida pela metade nunca fica em branco e nunca mostra chaves cruas.

long text: language blocks

A manifesto with highlights, links and emphasis is miserable to cram into a JavaScript string. So for long, marked-up prose, write one block per language and tag it with data-lang. Only the block that matches the page language is shown:

texto longo: blocos de idioma

Um manifesto com destaques, links e ênfases é uma tortura dentro de uma string de JavaScript. Então, para prosa longa e com marcação, escreva um bloco por idioma e marque com data-lang. Só o bloco que combina com o idioma da página aparece: 

<div data-lang="en"><p>Remember when the web was <b>weird</b>?</p></div>
<div data-lang="pt-BR"><p>Lembra quando a web era <b>esquisita</b>?</p></div>

With JavaScript on, the hiding rules are generated from your language list, so there's nothing to keep in sync. For visitors with JavaScript off, add the optional stylesheet, so they see exactly one language instead of all of them:

Com JavaScript ligado, as regras que escondem os blocos são geradas a partir da sua lista de idiomas, então não há nada para manter em dia. Para quem está com o JavaScript desligado, adicione a folha de estilo opcional, para que vejam um idioma só em vez de todos: 

<link rel="stylesheet" href="things18n.css">

It covers about thirty common languages and matches by prefix, so <html lang="pt-BR"> shows blocks marked pt or pt-BR. For a language it doesn't list, add one rule in the same shape.

Ela cobre umas trinta línguas comuns e compara pelo prefixo, então <html lang="pt-BR"> mostra blocos marcados com pt ou pt-BR. Para um idioma que ela não lista, adicione uma regra no mesmo formato.

letting people choose

Use whichever you like. Style them yourself: things18n adds aria-pressed and aria-current to the active one and nothing else.

deixando a pessoa escolher

Use o que preferir. Estilize você mesmo: o things18n só adiciona aria-pressed e aria-current no ativo, e mais nada.

<script src="things18n.js" data-switcher>
The no-markup option: injects a small floating switcher. Give it a corner with data-switcher="bottom-left" (top-right is the default; also top-left, bottom-right). It hides itself if there is only one language, and any CSS of yours overrides it (.things18n-switcher). If your page already has its own switcher, it steps aside. A opção sem marcação: injeta um seletor flutuante pequeno. Escolha o canto com data-switcher="bottom-left" (o padrão é top-right; também top-left, bottom-right). Ele se esconde se houver só um idioma, e qualquer CSS seu o sobrescreve (.things18n-switcher). Se a sua página já tem um seletor próprio, ele sai de cena.
<nav data-i18n-switch="short"></nav>
Fills itself with one <button> per language. short gives “EN · PT”; leave the value out to get names like “English”, “Português (Brasil)”. Give a language a custom label with things18n.add(lang, dict, { label: 'Português' }). Se preenche com um <button> por idioma. short dá “EN · PT”; sem valor, mostra nomes como “English”, “Português (Brasil)”. Dê um rótulo próprio com things18n.add(lang, dict, { label: 'Português' }).
<button data-i18n-set="pt-BR">
A button you write yourself that sets one specific language. Um botão que você mesmo escreve e que define um idioma específico.
<button data-i18n-toggle>
Cycles to the next language. Handy when you only have two. Passa para o próximo idioma. Prático quando só há dois.
<select data-i18n-select></select>
A dropdown. Leave it empty and it fills itself. Uma lista suspensa. Deixe vazia e ela se preenche sozinha.

writing messages

Dictionaries are plain objects. Nest them as deep as you like; keys join with dots:

escrevendo mensagens

Dicionários são objetos simples. Aninhe como quiser; as chaves se juntam com ponto:

things18n.add('pt-BR', {
  nav: { home: 'Início', about: 'Sobre' },          // t('nav.home')
  welcome: 'Bem-vinda, {name}!',                    // t('welcome', { name: 'Ana' })
  braces: 'Use {{chaves}} assim'                    // "Use {chaves} assim"
});

plurals

Give a message the plural forms (zero, one, two, few, many, other; other is required) and pass a count. The right form is chosen with the browser's own Intl.PluralRules, so languages with complicated plurals work too. Exact matches written as '=0' or '=1' win over the grammar rules.

Always add '=0' for Portuguese: in Portuguese, “0” counts as singular, so without it you'd get “0 carta”.

plurais

Dê à mensagem as formas de plural (zero, one, two, few, many, other; other é obrigatória) e passe um count. A forma certa é escolhida com o Intl.PluralRules do próprio navegador, então idiomas com plurais complicados também funcionam. Correspondências exatas escritas como '=0' ou '=1' vencem as regras gramaticais.

Sempre coloque '=0' em português: em português, o “0” conta como singular, então sem isso sairia “0 carta”. 

things18n.add('en', {
  cart: { '=0': 'Your cart is empty', one: '{count} item', other: '{count} items' }
});
things18n.t('cart', { count: 3 });   // "3 items"

the JavaScript API

Everything lives on window.things18n. Use it for text your own scripts create.

a API em JavaScript

Tudo fica em window.things18n. Use para os textos que os seus próprios scripts criam.

add(lang, messages, { label })
Register (or extend) a language. Call it as often as you like, in any order. A language you add is available immediately, even if it wasn't in data-langs. Registra (ou amplia) um idioma. Chame quantas vezes quiser, em qualquer ordem. Um idioma adicionado fica disponível na hora, mesmo que não estivesse em data-langs.
t(key, params?, lang?)
Returns the message as a string (with fallbacks). In key-less style the key is just your source text: t('Save changes'). A key found nowhere returns the key itself and logs one console warning. Devolve a mensagem como string (com os fallbacks). No estilo sem chave, a chave é só o seu texto original: t('Salvar alterações'). Uma chave que não existe em lugar nenhum devolve a própria chave e avisa uma vez no console.
setLang(lang) → boolean
Switch language, remember the choice, update the page, fire the events. Accepts loose tags: 'pt', 'pt-PT' and 'pt_BR' all land on 'pt-BR' if that's what you offer. Returns false for an unsupported language. Troca o idioma, lembra a escolha, atualiza a página, dispara os eventos. Aceita tags soltas: 'pt', 'pt-PT' e 'pt_BR' caem em 'pt-BR' se é isso que você oferece. Devolve false para um idioma sem suporte.
lang · langs · default
The current language, the list of available ones, and the default (read-only). O idioma atual, a lista dos disponíveis e o padrão (somente leitura).
onChange(callback) → unsubscribe
Called as callback(newLang, previousLang) after the DOM has been updated. Re-render anything your own scripts built. Chamado como callback(novoIdioma, idiomaAnterior) depois que o DOM foi atualizado. Redesenhe o que os seus próprios scripts construíram.
apply(root?)
Translate the data-i18n* elements inside root (default: the whole document). Call it after you insert new markup. Traduz os elementos data-i18n* dentro de root (padrão: o documento todo). Chame depois de inserir marcação nova.
pick(object, lang?)
For data that carries its own translations, like { en: 'Game', 'pt-BR': 'Jogo' }. Falls back to the default language, then to the first value. Plain strings pass through, so a field can be either. Para dados que carregam as próprias traduções, como { en: 'Game', 'pt-BR': 'Jogo' }. Recorre ao idioma padrão e, depois, ao primeiro valor. Strings comuns passam direto, então um campo pode ser dos dois jeitos.
has(key, lang?) · ready(callback)
Does a key exist in a language? / Run something once the DOM has first been translated. Uma chave existe num idioma? / Rode algo quando o DOM tiver sido traduzido pela primeira vez.
formatNumber(n, options?) · formatDate(date, options?)
Thin wrappers over Intl that use the current language: 1,234.5 vs 1.234,5. Atalhos para o Intl que usam o idioma atual: 1,234.5 ou 1.234,5.
debug(on?) · report()
Turn debug mode on or off from code (it is also on with ?i18n=debug). report() returns what is missing right now and prints it to the console. See finding what's missing. Liga ou desliga o modo debug pelo código (ele também liga com ?i18n=debug). report() devolve o que está faltando agora e imprime no console. Veja achando o que falta.
init({ langs, default, param, storageKey, warn, switcher })
Optional. Same as the script attributes, if you'd rather configure from JavaScript. Opcional. O mesmo que os atributos da tag de script, se preferir configurar pelo JavaScript.

events

Besides onChange, a things18n:change event fires on document with event.detail = { lang, previous }, for code that doesn't want to import anything.

eventos

Além do onChange, um evento things18n:change dispara no document com event.detail = { lang, previous }, para o código que não quer depender de nada.

things18n.onChange(function (lang, previous) {
  renderMyList();            // anything you built with t()
});

which language do you get?

In this order, first match against your available languages wins:

  1. ?lang=pt-BR in the URL. Great for sharing a link in a specific language. It doesn't overwrite the visitor's saved choice, but if they click the switcher, the URL updates too so a reload keeps their choice.
  2. The saved choice in localStorage (key things18n:lang).
  3. The browser's languages (navigator.languages), in the visitor's own order.
  4. Your default (data-default).

<html lang> is set before the page is first painted, so there is no flash of the wrong language, and right-to-left languages (Arabic, Hebrew, Persian, Urdu…) also get dir="rtl". Storage can be blocked (private windows, strict settings): everything still works, it just isn't remembered.

qual idioma a pessoa recebe?

Nesta ordem, vale o primeiro que combinar com os seus idiomas disponíveis:

  1. ?lang=pt-BR na URL. Ótimo para compartilhar um link num idioma específico. Não sobrescreve a escolha salva do visitante, mas se ele clicar no seletor, a URL também é atualizada para que um reload mantenha a escolha.
  2. A escolha salva no localStorage (chave things18n:lang).
  3. Os idiomas do navegador (navigator.languages), na ordem do próprio visitante.
  4. O seu padrão (data-default).

O <html lang> é definido antes da primeira pintura da página, então não há flash do idioma errado, e idiomas da direita para a esquerda (árabe, hebraico, persa, urdu…) também recebem dir="rtl". O armazenamento pode estar bloqueado (janela privada, configurações rígidas): tudo continua funcionando, só não é lembrado.

settings

Attributes on the script tag:

configurações

Atributos na tag de script:

data-default="en"
The language your HTML is written in, and the last stop before the original markup. Optional: it defaults to your <html lang>, and to en if that is missing. O idioma em que o seu HTML está escrito, e a última parada antes da marcação original. Opcional: o padrão é o seu <html lang>, e en se ele não existir.
data-langs="en,pt-BR"
The languages you offer. Optional: every language you add() is picked up anyway. Useful to list one in advance, before its dictionary exists. Os idiomas que você oferece. Opcional: todo idioma que você usar em add() entra de qualquer jeito. Útil para listar um antes de o dicionário existir.
data-switcher="top-right"
Adds the floating language switcher (see letting people choose). Adiciona o seletor de idioma flutuante (veja deixando a pessoa escolher).
data-param="lang"
The URL parameter to read. Use data-param="" to turn that feature off. O parâmetro da URL a ler. Use data-param="" para desligar o recurso.
data-storage-key="things18n:lang"
Where the choice is saved. Pages on the same site share it by default, so picking a language once applies everywhere (that's how the notebook and MeAsocie agree). Use a different key to keep a page separate. Onde a escolha é salva. Páginas do mesmo site compartilham por padrão, então escolher um idioma uma vez vale em todas (é assim que o caderno e o MeAsocie combinam). Use outra chave para manter uma página separada.
data-quiet
Silence the console warnings about missing keys. Silencia os avisos do console sobre chaves ausentes.

finding what's missing

Add ?i18n=debug to the page's address. That's the whole tool, and it runs in the browser. Switch to another language and:

  • every element with no translation gets a red dashed outline;
  • a badge in the corner counts them, along with any t() key that came up empty, gaps between your dictionaries (a key one language has and another lacks), keys whose {params} differ between languages, and how many data-lang blocks exist per language (a lopsided count means a forgotten block). It turns green when everything is in order;
  • the console lists the same, in text you can search. things18n.report() gives it to you as an object.

achando o que falta

Adicione ?i18n=debug ao endereço da página. Essa é a ferramenta inteira, e roda no navegador. Troque para outro idioma e:

  • todo elemento sem tradução ganha um contorno vermelho tracejado;
  • uma etiqueta no canto conta quantos são, junto com qualquer chave de t() que ficou vazia, lacunas entre os dicionários (uma chave que um idioma tem e outro não), chaves cujos {params} diferem entre idiomas e quantos blocos data-lang existem por idioma (uma contagem desigual significa um bloco esquecido). Ela fica verde quando está tudo em ordem;
  • o console lista o mesmo, em texto que dá para pesquisar. things18n.report() entrega isso como objeto.

adding a language

  1. Add it to the list: data-langs="en,pt-BR,es".
  2. Write its dictionary: things18n.add('es', { … }). Copy an existing one and translate the values.
  3. Translate your language blocks: one more <div data-lang="es"> next to the others, and one more rule in things18n.css if it isn't one of the thirty it covers.
  4. Check nothing was forgotten: open the page with ?i18n=debug.

adicionando um idioma

  1. Coloque na lista: data-langs="en,pt-BR,es".
  2. Escreva o dicionário: things18n.add('es', { … }). Copie um existente e traduza os valores.
  3. Traduza os blocos de idioma: mais um <div data-lang="es"> ao lado dos outros, e mais uma regra no things18n.css se ele não for um dos trinta que ele cobre.
  4. Confira se nada ficou para trás: abra a página com ?i18n=debug.

good to know

  • Key-less means the text is the contract. If you edit the source sentence, its translations stop matching (the check script and ?i18n=debug will tell you). For apps and text that changes often, use keys.
  • Dictionaries are .js, not .json. A fetch() of JSON doesn't work from file:// and would flash the wrong language while it loads.
  • Load order matters once: things18n first, then your add() calls, then scripts that call t(). After that, anything goes.
  • A namespace can't have a child called other: an object with an other key is read as a plural message.
  • Offline apps (service workers): add things18n.js and your dictionary files to the precache list.
  • Several tabs? Changing the language in one updates the others.
  • Text a game or app generates (like a status line) is best stored as a key plus params and rendered with t() inside an onChange handler, so it re-translates by itself.

bom saber

  • Sem chave, o texto é o contrato. Se você editar a frase original, as traduções deixam de combinar (o script de checagem e o ?i18n=debug avisam). Para apps e textos que mudam muito, use chaves.
  • Dicionários são .js, não .json. Um fetch() de JSON não funciona em file:// e piscaria o idioma errado enquanto carrega.
  • A ordem de carregamento importa uma vez só: things18n primeiro, depois os seus add(), depois os scripts que chamam t(). Depois disso, vale tudo.
  • Um namespace não pode ter um filho chamado other: um objeto com chave other é lido como mensagem de plural.
  • Apps offline (service workers): inclua o things18n.js e os arquivos de dicionário na lista de pré-cache.
  • Várias abas? Trocar o idioma em uma atualiza as outras.
  • Texto que um jogo ou app gera (como uma linha de status) é melhor guardado como chave mais parâmetros e desenhado com t() dentro de um onChange, para se retraduzir sozinho.
